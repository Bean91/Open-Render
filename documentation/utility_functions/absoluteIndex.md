```cpp
uint64_t absoluteIndex(int x, int y, int z);
```
---
## Basic Info
Returns the index for the absolute points array based on inputted X, Y, and Z coordinates.
### Return Type
returns a `uint64_t`

### Parameters
| Parameter | Type  | Use                   | Optional |
|-----------|-------|-----------------------|----------|
| `x`       | `int` | X Coordinate of point | ❌        |
| `y`       | `int` | Y Coordinate of point | ❌        |
| `z`       | `int` | Z Coordinate of point | ❌        |
---
## Example

```cpp
// Calling the absoluteIndex() function
const uint64_t = absoluteIndex(420, 300, 95);
```
