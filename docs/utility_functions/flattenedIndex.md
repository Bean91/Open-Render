```cpp
uint64_t flattenedIndex(int x, int y, int z);
```
---
## Basic Info
Returns the index for the flattened points array based on inputted X and Y coordinates.
### Return Type
returns a `uint64_t`

### Parameters
| Parameter | Type  | Use                   | Optional |
|-----------|-------|-----------------------|----------|
| `x`       | `int` | X Coordinate of point | ❌        |
| `y`       | `int` | Y Coordinate of point | ❌        |
---
## Example

```cpp
// Calling the flattenedIndex() function
const uint64_t = flattenedIndex(420, 300);
```
